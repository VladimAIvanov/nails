# Интерфейс клиента

Обычные HTML, CSS и JS — без сборщиков и фреймворков. Правила: [docs/frontend-rules.md](../docs/frontend-rules.md). Откуда каждый экран берёт данные: [docs/ui-map.md](../docs/ui-map.md).

## Запуск

```bash
cd server && npm start
```

Открыть <http://localhost:3000>. Отдельный сервер для страниц не нужен: их отдаёт тот же процесс, что и API. Всё, что начинается с `/api`, — API, остальное — файлы отсюда.

Так сделано из-за пропуска: он лежит в куке, которую ставит сервер, а кука привязана к источнику. Разные порты — и браузер не пришлёт её вместе с запросом.

## Что где

| Файл | Экран |
|---|---|
| `index.html` | лендинг: услуги, мастера, работы, контакты |
| `login.html` | вход |
| `register.html` | регистрация клиентки |
| `password-reset.html` | восстановление доступа |
| `password-change.html` | смена пароля вошедшей клиенткой |
| `sessions.html` | устройства и входы |
| `booking.html` | запись, шаг 1: выбор услуг |
| `booking-master.html` | шаг 2: мастер или «любой свободный» |
| `booking-time.html` | шаг 3: календарь и свободные окна |
| `booking-confirm.html` | шаг 4: сводка, удержание, подтверждение |
| `booking-done.html` | запись создана |
| `account.html` | кабинет: активные записи и история |
| `appointment.html` | детали визита, отмена и перенос |
| `profile.html` | профиль: данные, напоминания, избранное, согласия |

| Общий код | Зачем |
|---|---|
| `js/api.js` | единственное место, где страница ходит на сервер; там же показ ошибок и форматирование |
| `js/header.js` | общая шапка: логотип, меню, имя вошедшего или кнопки входа |
| `js/<экран>.js` | код конкретного экрана |
| `css/base.css` | общие стили: раскладка, кнопки, формы, карточки |
| `css/landing.css` | стили лендинга |
| `tokens.css` | цвета, шрифты, размеры из дизайн-системы прототипа |

`draft/` — то, что осталось от чернового стенда: страница студии `/draft/admin.html`. Клиентские черновые страницы удалены — их заменили настоящие экраны. Эта останется до сборки админ-панели: ею удобно дёргать административные адреса, для которых чистовых экранов ещё нет.

## Правила, которые здесь соблюдаются

- **Запросы — только через `js/api.js`.** Внутри страниц ни одного `fetch`.
- **Значения — только из `tokens.css`.** Ни цветов, ни шрифтов, ни размеров цифрами.
- **Пропуск не хранится.** Ни `localStorage`, ни заголовка `Authorization`: сервер ставит куку `HttpOnly`, браузер сам её присылает. Скрипты страницы её не видят.
- **Ошибка сервера — текстом на экране.** И по нажатию, и при первой загрузке. Пока данные едут — заглушка, а не пустое место.
- **Никаких инлайновых скриптов и стилей**: их запрещает политика безопасности, с которой отдаются страницы.
