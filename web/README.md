# Черновой фронтенд

Простые страницы поверх готового API — формы, списки и кнопки. Задача одна: проверять работу сервиса руками. Дизайна здесь нет намеренно; оформление живёт в прототипе (`site/`), который этот код не трогает.

## Запуск

Нужны два процесса. Сначала API:

```bash
cd server && npm start
```

Затем в другом окне — страницы:

```bash
cd server && npm run web
```

Открыть <http://127.0.0.1:5173>.

Порт страниц задаётся переменной `WEB_PORT` (по умолчанию 5173), адрес API — `PORT` и `API_HOST` из общего `.env`.

## Почему свой сервер, а не открыть файлы напрямую

Файл, открытый как `file://`, не может обращаться к API: браузер считает это межсайтовым запросом. Поэтому `serve.js` отдаёт страницы и **переправляет всё, что начинается с `/api`, на бэкенд**. Браузер видит один источник — не нужны ни настройка `CORS_ORIGINS`, ни послабления в заголовках безопасности API.

## Страницы

| Файл | Что проверяет |
|---|---|
| `index.html` | регистрация, вход, состояние сеанса |
| `catalog.html` | услуги, категории, мастера, сведения о студии |
| `slots.html` | расчёт свободного времени: мастер, дата, набор услуг |
| `book.html` | удержание окна и создание записи, разбор отказа «время занято» |
| `account.html` | свои записи, детали, перенос, отмена |
| `admin.html` | все записи с фильтрами, оформление записи, услуги, мастера, расписание мастера |

Общий код — в `app.js`: сеанс в `localStorage`, обёртка над `fetch`, вывод ошибок, форматирование денег и времени.

## Как здесь показываются ошибки

Любая ошибка API попадает на страницу текстом — с кодом, человеческим заголовком и сообщением сервера. Два случая разобраны отдельно:

- **409 «время занято»** — сервер присылает ближайшие свободные окна, они выводятся кнопками: нажатие подставляет время в форму, можно сразу повторить;
- **400 с разбором полей** — показывается, какое поле не принято.

Токен, который сервер перестал признавать, стирается, и страница уводит на вход, а не показывает пустой список.

## Что нужно знать при проверке

- Время в API всегда UTC и заканчивается на `Z`. Страницы показывают его по часовому поясу студии; поле ввода ждёт ISO-8601 — проще выбрать окно на странице «Свободное время», кнопка подставит значение сама.
- Деньги в API — целые копейки. В рубли переводит интерфейс.
- Клиентка записывает только себя; администратор оформляет запись за неё на странице «Студия». Признак «поверх занятого времени» принимается только на административном адресе.
- Мастер, вошедший в «Студию», увидит своё расписание — административные разделы ему закрыты сервером.
