# Документы проекта

| Документ | Где лежит | О чём |
|---|---|---|
| [Схема базы данных](db-schema.md) | `docs/db-schema.md` | Таблицы, поля, связи, ограничения и индексы сервиса записи |
| Карта связей | [`site/Карта связей.dc.html`](../site/Карта%20связей.dc.html) | Семь страниц прототипа и все переходы между ними |
| [Паспорт продукта](Паспорт%20продукта.docx) | `docs/Паспорт продукта.docx` | Суть, цели, роли, функции и сценарии сервиса |

Карта связей лежит в `site/`, а не здесь: страница подтягивает дизайн-систему и `support.js` относительными путями и открывается только рядом с ними. Верхнее меню всех страниц прототипа тоже ссылается на неё как на соседний файл.

Чтобы посмотреть прототип, откройте любую страницу из `site/` в браузере — например `site/Карта связей.dc.html`, с неё есть переходы на все остальные.
