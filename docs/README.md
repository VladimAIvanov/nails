## Про карту связей

В `docs/` лежит копия страницы с переписанными путями: она подтягивает дизайн-систему и `support.js` из `../site/`, поэтому открывается прямо отсюда. Рабочий оригинал — [`site/Карта связей.dc.html`](../site/Карта%20связей.dc.html): именно на него ссылается верхнее меню всех страниц прототипа.

Файла два, содержимое одно. При правке карты в `site/` копию в `docs/` нужно обновить — иначе они разойдутся. Разница между ними только в префиксе `../site/` у ссылок.

## Как посмотреть прототип

Откройте в браузере любую страницу из `site/` — например `site/Карта связей.dc.html`, с неё есть переходы на все остальные шесть.
